# CalculatorPY
Calculatrice simple en Python pour pratiquer les bases: addition, soustraction, multiplication et division avec validation des entrées.

L'utilisateur choisit l'opération dans un menu et peut faire plusieurs calculs jusqu'à ce qu'il décide de quitter. Le programme vérifie que les nombres sont corrects et gère la division par zéro. 

J'ai appris à utiliser des fonctions pour organiser le code, travailler avec des boucles, demander et vérifier les entrées de l'utilisateur et gérer les erreurs de base avec try/except. C'est un projet parfait pour pratiquer la logique, les bases de la programmation et la gestion d'erreurs simples en Python.
